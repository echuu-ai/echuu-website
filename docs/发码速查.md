## 一、发一个码给某人(最常用)

1. 打开 Sheet → `Codes` 表。
2. 挑一行 `status = unused` 的码。
3. 在那一行填:
   - **assigned_email**:对方邮箱(记一下发给谁了,可留空)
   - **expires_at**:想设有效期就填(如 `2026-12-31`),**留空 = 永不过期**
   - **status** 改成 `sent`,**sent_at** 填今天(可选,只是方便自己追踪)
4. 用 cory@echuu.ai 把这个码发给对方(微信/邮件都行)。
5. 对方到 www.echuu.ai → 点「登录」→ 输码 → 自动进产品站。
   成功后这一行会**自动**变成 `status=redeemed` + 写入 redeemed_at / redeemed_ip,不用你管。

> 列顺序(A→I):`code | assigned_email | status | created_at | sent_at | expires_at | redeemed_at | redeemed_ip | note`
> 你只需要碰 **assigned_email / status / expires_at** 这三列,其余机器自己写。

## 二、码不够了,再生成一批

本地在 echuu-official-website 仓库跑:

```bash
node scripts/invite-codes.mjs --count 50 --note "10月第二批"
```

会生成一个 `invite-codes-YYYY-MM-DD.csv`(已被 gitignore,不会进仓库)。
把里面的 **code 那一列**复制,粘到 Sheet `Codes` 表的 A 列新行,把 **status 填 `unused`** 即可。
(CSV 的列和 Sheet 不完全一样,只认 code 列 + status=unused 就行,别整列乱贴。)

## 三、状态含义

| status | 意思 |
|---|---|
| `unused` / `sent` | 可用(sent 只是你标记已发出) |
| `redeemed` | 已被兑换,作废,不能再用 |
| 过期 | expires_at 到期后自动失效(前端提示无效) |

## 四、安全红线

- **CSV 和码别发群里**——码就是登录凭据。
- 服务账号私钥、Vercel 环境变量不外发、不进仓库。
- 想作废某个已发的码:把该行 status 改成 `redeemed`(或删掉 code),立即失效。

## 五、出问题自查

- 输码提示「无效」:确认该行 status 是 unused/sent、没过期、码没抄错。
- 全部码都报未开放:八成是 Vercel 环境变量没配全或没重新部署,见 [beta-redeem-setup.md](beta-redeem-setup.md)。
