# 出道高光（已实现，本地）

开场进入 hero 时触发一次 3.2 秒高光；重播后再次触发，普通滚动不会触发。

- R3F 在既有 rim 位置增加银蓝方向光，沿共享开场时钟淡入、缓慢淡出。既有灯光参数不修改；高光结束额外光强归零。
- 12 片银色纸屑分布在画面两侧，以 transform/opacity 下落、翻转、淡出。600px 以下最多 8 片，不接收指针事件。
- Logo 掠光使用原 PNG alpha 蒙版，0.38 秒后开始，一次扫过；保留原响应式尺寸与位置。
- 3.2 秒后移除纸屑与掠光 DOM。组件卸载/重播清理定时器。
- prefers-reduced-motion 时不挂载装饰，现有静态降级也不加载新增 3D 灯光。无声音、无循环。

验证：14 项测试通过，包含光强包络起止/范围/单次消退；TypeScript 和生产构建通过；浏览器检查重播、跳过后的触发，纸屑/Logo 层出现与结束移除、窄屏 Logo 居中。未做真机性能基准。

## 后续调整

按用户要求移除所有银白纸屑，仅保留短暂侧后光和 Logo 掠光。指尖十字光尚未实现。

## 指尖十字光

已替换为 0.75 秒十字星光：0–0.32 秒从左上划入，食指末节骨骼延长线估算指尖，投影至画布尺寸定位，随后闪亮淡出。使用清晰 SVG 图层避免被场景景深模糊；每帧复用向量，无 React 状态更新，卸载清理 DOM。移除 Logo 掠光触发，侧后光降至 0.35；无纸屑。浏览器验证轨迹、指尖落点及结束隐藏。14 项测试与构建通过。
