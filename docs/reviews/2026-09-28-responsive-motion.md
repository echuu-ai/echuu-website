## 按设计奖项常见质量维度进行内部评审

这不是 Awwwards/Webby 官方评分，也不宣称已达到获奖标准。

- 视觉：保留品牌配色与原稿胸针、星芒、天使；修复接缝原因。多视口视觉一致性仍待验证。
- 交互：绝对时间采样消除帧率相关漂移；手机卡片由用户控制。真实开场录像与触摸操作仍待验证。
- 可读性/可访问性：正文去描边，功能说明加深颜色，保留 reduced-motion 和重播。尚未进行完整对比度/读屏审核。
- 技术：不增加运行时依赖，资源清单完整。主包及 3D chunk 仍触发 500kB 提示；未测手机 GPU 帧率和 Web Vitals。

## 验证及阻塞

- npm test：9 项，包括原时间线测试、60fps/10fps/跳转/重播的 Three.js 姿态一致性、权重守恒、锁定姿态连续性、竖屏构图补偿，以及持续 600 帧 IK 不累积。
- npm run check:assets：106 项，0 缺失/变更。
- npm run build：TypeScript 与 Vite 成功；存在既有大 chunk 提示。
- CUA 浏览器接口多次超时或 nodeRepl.fetch 失败。尝试原生 Chrome 时窗口目标在不同 profile 间变化，无法可靠绑定目标页面，停止继续操作。未获取到本轮可采信的官网截图；未用其他网站截图充当验收证据。
