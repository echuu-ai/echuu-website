# 参考站抓取：Metalab 与 Rava Labs（2026-09-30）

目的：Cory 不希望官网有「AI 味很重的 UI」。抓两个参考站的实际排版参数与结构，对照我们首页，列出可执行的收敛项。以下数据来自 2026-09-30 在 1440×900 视口用内嵌浏览器读取的计算样式与页面文本，不是主观印象。

## Metalab（metalab.com）

| 项 | 实测 |
|---|---|
| 底色 / 文字 | `#000` / `#fff`，全站只有黑、白、一个灰（`#bababa`） |
| 标题字体 | PP Eiko（衬线），88px，字重 240，字距 -1.76px，行高 1.18 |
| 正文字体 | Basis Grotesque Pro，16px，字重 350–400 |
| 页头 | 左「Menu」胶囊、中间品牌字、右侧当地时间 + 一个方块按钮；高度约 40px |
| 首屏 | 一个 3D 星形雕塑占满，之后只有一句话「We make interfaces」两行错位，右上一段 3 行说明 |
| 导航 | 客户名做成一列小胶囊贴在左侧（Robinhood、Midjourney、Uber…），是内容，不是装饰 |
| 圆角 | 只有胶囊按钮是全圆角；内容块无圆角、无描边、无阴影 |
| 装饰 | 没有渐变、没有玻璃拟态、没有星星 / 火花，整页留白超过 60% |

## Rava Labs（ravalabs.com）

| 项 | 实测 |
|---|---|
| 底色 / 文字 | `#fff` / `#000`，辅色只有 `#f5f5f5`、`#fafafa`、`#111`，一处 10% 的 `#12a7ff` |
| 标题字体 | Suisse Intl Book，23.4px，字重 450，字距 -1.2px；首屏 RAVA LABS 用超大字距的粗字做「字标」 |
| 正文字体 | Suisse Intl / PP Neue Montreal，12px（！），行高 30px 的标题只有 23px |
| 页头 | 一个居中的小胶囊（「Work」+ 圆点），不是整条 bar |
| 布局 | 作品用真实摄影 + 设备实拍，两列错落大图；数据（$46M、+24、+4）用大数字 + 方括号小标 |
| 圆角 | 12 / 16 / 20px，按钮 9998px；无玻璃、无外发光 |
| 动效 | 首屏字标粒子化淡出，之后只有滚动位移 |

## 两站共同点（= 「不像 AI」的手法）

1. 一套色：一黑一白加一个灰，品牌色出现一次。
2. 字体等级少：一个展示字体 + 一个正文字体；正文偏小（12–16px），标题靠字重轻、字距负、留白大取得气质，不靠描边、阴影、发光。
3. 页头是「一个小对象」（胶囊 / 品牌字 / 时间），不是通栏。
4. 内容即装饰：客户名、数字、真实截图、真实摄影。没有星星、闪光、彩色渐变球、玻璃卡片堆叠。
5. 每屏只说一句话；一屏内不超过两种字号。
6. 元素对齐到一个明确的栅格；错位是有意的（两行标题右移、图片两列高低错开），不是随机漂浮。

## 对照我们首页（website/{locale}）当前状态

| 现状 | 触发「AI 味」的原因 | 建议 |
|---|---|---|
| 首屏 UI 之外，正文区大面积玻璃卡（简介、三步、功能卡、模式卡、博客卡） | 玻璃 + 内发光 + 圆角 + 半透明白，是生成式 UI 最常见的组合 | 卡片改为**纯白 / 纯色面 + 1px 线**或**无卡片直接排版**；只保留设计稿明确画了玻璃的地方（首屏 CTA 条、内测按钮） |
| 星星、火花、翅膀、飞马、剑等装饰同时出现在多屏 | 装饰密度高，且互相无叙事关系 | 首屏开场保留（那是设计稿的黑场），进入正文后每屏最多一个装饰主角；星星只在「打造多样 OC 直播间」功能卡里保留（设计稿有） |
| 蒲瓜纤云宋 + 1pt 白描边 + 42dot Sans + Agu Display「3」+ Inter（模式卡） | 一屏内 3–4 种字体 | 正文与 UI 统一为 42dot Sans；Inter 从模式卡去掉；Agu Display 只用于那个「3」 |
| 标题 64px、说明 24px、正文 16px，字重全为 300 | 等级靠字号堆 | 说明文字降到 15–16px、字距 -0.02em；标题保持大但行高收到 1.0 |
| 每个区块都有大标题 + 副标题 + 卡片 | 结构重复 | 三步、模式、博客三处至少一处改成「无标题、内容直接开始」（Metalab 的客户列做法） |
| 页脚从天空色渐变到深蓝 + 大字 | 渐变面积大 | 渐变保留（设计稿有），但页脚链接改为两列小字 12–13px，行高 2，去掉列标题的粗体 |
| 文本阴影已去；圆角 19 / 21 / 14 / 12 / 34px 不统一 | 圆角族多 | 收敛为 12 / 20 / 999 三档 |

## 不建议照搬的

- 黑底：与设计稿蓝白天空冲突，只在开场黑场使用。
- 12px 正文：中文可读性差，中文正文下限 15px。
- 首屏字标粒子化：我们已经有 3D 开场，不叠加第二套首屏动效。

## 执行状态

本文只记录抓取结果与建议，未改任何样式；首页 / 团队页当前有另一会话在并行修改（TeamChrome、team.css），样式收敛需要在那批改动落地后统一做，避免冲突。
