## 2. 现在为什么「没有电影感」（诊断）

1. **镜头是「关键帧之间直线插值 + 阻尼」**：每两个关键帧之间是一段 smoothstep，到点就减速到停、再起步。观众感到的是「一格一格挪」，而不是一条连续的运动。
2. **镜头没有动机**：多数运动和角色动作不同步（她翻身时镜头在平移、她站起时镜头在拉远），运动不是被动作「带」出来的。
3. **没有镜头语言的层次**：全程几乎都是中景、焦距在 28–38° 之间小幅变化，没有特写 / 大远景的对比，没有低角度、没有仰拍的英雄镜头。
4. **转场不靠画面衔接**：纸 → 3D 是交叉淡化；站起 → 折纸是硬切换注意力；纸飞机 → 开窗靠白闪。没有 match cut（形状 / 运动匹配）。
5. **焦点不讲故事**：景深只在定格时开；该「把视线从人拉到纸」的地方没有拉焦。
6. **没有呼吸**：镜头在静止段是死的；运动段又太匀。缺少手持微动、预备动作（anticipation）与停顿（hold）。
7. **声音和光不跟拍点**：显形、苏醒、折纸、起飞都没有对应的音效或光的变化。

## 3. 导演流程（分镜表）

时间从「画完翅膀」那一刻算 0（draw 阶段不计时）。镜号后的括号是景别 / 焦段（以竖直 fov 表示，越小越长焦）。

### 第零幕 · 白纸（draw，不计时）
| 镜 | 画面 | 镜头 | 声音 / 光 |
|----|------|------|-----------|
| 0-1 | 黑场里纸落下来（1.1 s），提示语一个字母一个字母写出，轮廓一笔一笔写出（2.4 s），右翼引导浮现并呼吸 | 俯拍定机位，**极轻手持漂移**（±0.3 %，周期 6 s），让画面是活的 | 铅笔沙沙声随书写；纸落下的轻响 |
| 0-2 | 观众画翅膀：引导随落笔变淡，画够后轮廓泛蓝光 | 同上 | 画够时一声风铃 |

### 第一幕 · 苏醒（0 – 8.3 s）
| 镜 | 时间 | 画面 / 动作 | 镜头（景别 · fov · 运动） | 转场与动机 | 声音 / 光 |
|----|------|-------------|---------------------------|-------------|-----------|
| 1-1 | 0 – 1.8 | 光的前沿沿身体**从头扫到脚**，角色从铅笔稿里显形 | 俯拍特写→近景 · 32° · **沿身体轴向慢推**（跟着光的前沿从头走到胸，推 8 %） | DOM 纸与 3D 纸完全重合后才动（0.3 s 内不动） | 显形时一段上扬的 shimmer；bloom 随前沿短暂抬升 |
| 1-2 | 1.8 – 3.4 | 睡姿呼吸一下 → **翻身**成仰躺 | 近景 · 32→38° · **绕身体旋转 30° 并降低机位**（crane down），旋转方向与翻身方向一致 | **动作带动镜头**：翻身开始的同一帧镜头开始转 | 翻身一声布料摩擦 |
| 1-3 | 3.4 – 6.0 | 坐起 | **低机位**（离地 0.35 m）· 46° 广角 · **仰拍，向后拉**，让她在画面里「升起来」 | 坐起的瞬间镜头开始后退（cut on action 的连续版） | rim 光开始亮起 |
| 1-4 | 6.0 – 7.6 | 站起、翅膀展开 | 中景仰拍 · 40→34° · **升降臂上升到胸口高度**，同时轻微环绕 15° | 站直时镜头刚好到眼平，**速度连续不停** | 翅膀展开一声羽毛扑动；rim 光到峰值 |
| 1-5 | 7.6 – 8.3 | **英雄停顿**：她抬眼看镜头 | 近景（胸以上）· 30° · **静止 0.5 s 后极慢推进**（dolly-in 3 %） | 全片第一个 hold，让观众「认识」她 | 呼吸声，环境声压低 |

### 第二幕 · 纸飞机（W = 8.6 s 起，共 5.4 s，节奏放慢）
> 2026-10-03 Cory：折纸飞机应该是一个**慢慢的过程**，那时镜头应该**转到角色背后**，角色才能衔接后面（开窗那段镜头在她身后）。

| 镜 | 时间 | 画面 / 动作 | 镜头 | 转场与动机 | 声音 / 光 |
|----|------|-------------|------|-------------|-----------|
| 2-1 | W+0.3 – W+1.8 | 脚下的纸**慢慢飘起**，落到她面前、胸口高度 | 从正面 **绕到她右侧**（侧面：她低头看着纸，人与纸同框）· 34→40° · 焦点从脸拉到纸 | 纸的上升带动镜头环绕（motivated orbit） | 纸被风掀起 |
| 2-2 | W+1.8 – W+4.2 | 纸按真实折法**四拍慢慢折**（角 → 鼻 → 对折 → 翻翼，每拍 0.6 s） | 继续绕到 **高位 3/4 后侧**：越过翅膀与右肩俯看她面前的纸 · 34→33° · 焦点在纸上，她在前景虚化 | 每一折配一个极小的推近 | 四声折纸；最后一折时手机窗从黑暗里亮起（W+3.6） |
| 2-3 | W+4.2 – W+5.4 | 纸飞机**越过她往前飞**，钻进前方的窗口 | 留在她身后、稍后退升高，视线跟着飞机往前 · 38° | 镜头已在她身后 = 直接接开窗（同一方向、同一侧） | whoosh；入窗一声闷响 + 白闪 |

### 第三幕 · 开窗与定格（12.6 s 起，镜头与动作保持现状）
| 镜 | 内容 | 说明 |
|----|------|------|
| 3-1 | ④ open：手机窗放大到全屏，镜头退到角色后上方环绕；PET_INTRO → PET_INTRO_END → spot_target_locked | **保持**（Cory 满意）。唯一要求：进入时的速度要和 2-4 的飞机速度衔接，不能先停再走 |
| 3-2 | ⑤ hero 定格 + 首屏 UI 入场 + 眨眼 | 保持 |

## 3.5 研究：igloo.inc 的运镜（读的是线上 `App3D-f554a111.js` 源码）

igloo 拿过 Awwwards SOTD / Developer Award，运镜的「电影感」来自一套很简单但很严格的结构：

1. **两层相机**
   - **基础层（编排）**：`basePosition` / `baseTarget` 只由 GSAP 时间线驱动。
     **位置和注视点分开做动画、用不同的起点和缓动**：例如下降段位置从 +9 m 落下、注视点从 +14 m 落下，都是 `power2.out` 14 s；水平漂移从第 7 s 才开始，用 `power1.inOut`。
     注视点和机位不同时到达 → 镜头在运动中自然带出俯仰变化（look-ahead），而不是平移。
   - **附加层（质感）**：指针视差（以注视点为中心的球面偏移，位置 0.07 / 0.025 rad）、
     注视点的正弦噪声抖动（`sineNoise1`，0.01–0.02 rad，速度 0.1–0.5）、指针速度带来的滚转；
     全部用帧率无关的 `lerpFPS`（系数 0.02–0.035，约 0.5 s 的跟随）。
2. **开场是一次长的「摇臂降落」**：从 (−14, 21, 14) 的高空俯视，`introWeight` 在第 2 s 起用 5.5 s 从高空机位混合到场景机位（`inOut1`）；
   **指针影响 `touchAmount` 同时从 0 爬到 1（5 s）**——镜头落定之后才「活过来」，降落过程中绝不被鼠标打扰。
3. **长焦**：fov 25–30°；滚动快时 fov 加宽（`45 − 5·|velocity|`）制造速度感。
4. **永远重叠**：每段 tween 都和下一段重叠，相机从不完全停下；音量（风声、冰屋声）也跟着同一个进度 `fit()` 渐变。

### Awwwards / Webby 的标准落到这里
- **Design / Creativity**：每个镜头有动机、有景别变化、有一个记忆点（这里是「画出来的角色醒来」和「纸折成飞机飞进窗口」）。
- **Usability**：可跳过、可重播、减少动态效果时直接定格；任何情况下都进入首页。
- **Craft / Performance**：60 fps，无卡顿、无跳帧，镜头速度连续；资源加载藏在「画翅膀」的交互里。
- **Sound**：拍点有声音、默认很轻、可静音。

## 4. 镜头规则（给实现用）

1. **用样条代替分段插值**：相机位置与注视点各走一条 Catmull-Rom（或 Hermite）曲线，关键帧之间速度连续；只有标注为 hold 的地方才允许速度为 0。
2. **镜头锚点只跟随角色的「平滑后」位置**：对 hips / head 做 0.25 s 的低通，再给相机；避免跟着骨骼抖。
3. **焦段是表演的一部分**：显形（32°）→ 翻身（38°）→ 低角度坐起（46° 广角）→ 站起（40→34°）→ 英雄停顿（30°）→ 折纸特写（34°）→ 揭示（40°）。fov 与位置同一条曲线插值，避免「推镜头 + 变焦」互相抵消。
4. **拉焦**：2-1 用现有的 `HeroDepthOfField`，focusDistance 从脸平滑过渡到纸，用 0.6 s；其余段景深关闭或很浅。
5. **手持呼吸**：所有镜头叠一层低频噪声（位置 ±1.5 cm，旋转 ±0.3°，两个不同周期的正弦叠加），hold 段减半；`prefers-reduced-motion` 时为 0。
6. **预备动作与过冲**：每次大运动前 0.15 s 反向微动 1–2 %，到位时 2 % 过冲再回落（只用在 1-3、1-4、2-3）。
7. **转场都要有动机**：镜头开始运动的那一帧必须对应一个动作（翻身、坐起、纸飞起、飞机起飞）。
8. **声音与光是拍点**：显形 shimmer、翻身、羽翼、四声折纸、whoosh、入窗；rim 光在 1-3 → 1-4 升起，bloom 只在显形前沿与入窗白闪时抬升。音量服从现有静音开关。
9. **任何时候都不能卡死**：时间线由绝对时钟驱动；3D 画面落后时以时钟为准；超时（开场开始后 `OPENING_TOTAL + 5 s` 仍未到 hero）直接跳到定格。

## 5. 验收标准

- 从画完到定格全程无停顿：录屏逐帧看，相机速度曲线只在 1-5 有一次接近 0。
- 每一次镜头运动都能说出它的动机（对应第 3 节「转场与动机」列）。
- 2-4 → 3-1：飞机钻进窗口与开窗白闪在同一帧，3-1 的起始速度与飞机速度方向一致。
- 竖屏（390×844）与横屏（1440×900）都完整、主体不出画。
- `prefers-reduced-motion`：跳过开场直接定格。

## 7. 复核记录（2026-10-03，按 Webby / Awwwards 标准）

| 维度 | 发现 | 处理 |
|------|------|------|
| 有效性：引导 | 翅膀引导是真实羽翼俯视的碎片（两块、形状丑），用户看不懂要画什么 | 只取右翼最大的一块，按它的位置 / 主轴 / 大小重画成一片标准的翅膀造型（饱满前缘 + 四片圆头羽毛 + 三道羽轴），蓝色铅笔点线 |
| 有效性：提示语 | Cedarville Cursive 太花、不像随手写；文案偏说明 | 换 Reenie Beanie（铅笔随手写），文案「Draw its wings — make it live」，两行写在纸上、跟着纸倾斜，逐字写出；不加任何 UI |
| 完整性：书写感 | 轮廓是大幅正弦摆动，显得「歪扭七八」；静止时不动 | 改成「人拿铅笔沿轮廓描」：短笔分段、起落笔出头、轻重变化、只留很轻的手抖；静止时用 SVG 位移滤镜每秒换 8 次种子做 line boil（轮廓 / 引导 / 提示语一起） |
| 完整性：纸的大小 | 纸偏小（反复提到） | 画框放大到 1.24×（竖屏 196vw），上下出画；3D 纸面按 DOM 纸实测尺寸自动对上；纸的物理宽度改 1.95 m，人物在纸上留出头顶写字和脚下的空间 |
| 流畅性：显形对位 | 显形时 3D 身体偏离铅笔稿：透视视差（稿子是正交俯拍，相机是透视且在推近，身体离纸 10–30 cm） | 显形全程用长焦远机位（fov 16）正俯视并保持，身体完全显形后才开始动 |
| 镜头合理性 | 坐起段贴地正面低机位，正对双腿（不得体） | 改成低机位 3/4 侧面仰拍，跟着她后退升起 |
| 镜头合理性 | 折纸飞机对折时正对机尾，几乎看不见 | 折纸时机头横在画面里、纸面斜对镜头 45°，最后一拍再转向窗口 |
| 画面 | 镜头贴近时纸被 bloom 吹成一片白 | 交接时纯白，之后慢慢压到 0.86 |

### 仍可提升（下一轮）
1. **黑场太「空」**：第一幕、第二幕的 3D 背景是纯黑，只有纸和人。可以加一束顶光的光斑 / 极淡的纸屑尘埃，让空间有深度（参考 igloo 的雪粒子）。
2. **翻身那一下（≈3.4 s）**：从正俯视的远机位一口气落到低机位，运动很大；可以考虑在这里用一次「动作剪辑」（cut on action）代替长距离摇臂。
3. **开窗前后到定格（≈18 s）**：从她身后绕到定格机位时有一瞬间离她很近，构图别扭。
4. **竖屏**：手机上第二幕的过肩镜头需要单独的构图（现在沿用横屏机位 + 后拉）。
5. **音效**：目前是合成的占位音色，正式上线建议换成录制的纸张 / 羽毛 / 风声素材。
