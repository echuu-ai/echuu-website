## Prompt 开始

你是 Echuu 官网的设计与前端执行者。请依据以下任务书，完成一个面向 Original Character（原创角色）创作者的品牌官网，交付可运行、可浏览、可继续维护的实现。不要只给建议或线框图，也不要把任务书全文搬上网页。

### 1. 目标与工作方式

访客主要是创作 Original Character、写人设、画角色、委托皮套、制作 3D 模型的人。他们关心：我的角色能做什么、像不像我设定的角色、怎么试、画师和角色权利是否受尊重。

网站应让访客在首屏明白：Echuu 是面向 Original Character 的 AI VTuber 创作与直播平台。`AI VTuber` 是必须明确呈现的品类名称，不能只藏在页脚、SEO 或长段介绍里。主转化是申请内测；次转化是观看演示；画师与建模师有明确合作入口。

视觉方向：**蓝白天空里的 Original Character 舞台，带一点个人站与创作手账的亲近感。** 大角色、真实产品画面、短句、留白；少量轨道环、翅膀、纸飞机和手绘笔迹形成品牌识别。

直接完成素材盘点、页面设计、实现和验证。常规布局、间距、裁切、响应式选择自行决定。缺失信息集中写入 `OPEN_ITEMS.md`，继续完成不依赖它的部分。涉及真实对外发布、第三方账号配置、收费服务或改变正式条款的工作，另行交接，不自行执行。

不要把官网设计任务扩展成重做直播 app、后台系统或完整社区。首页内容齐全，独立页面有真实可用的最小实现。没有服务端时采用下文指定的降级行为。

所有动态有 `prefers-reduced-motion` 路径，包括淡入；不可见的视频/画布停止工作。字体与图片加载完成后更新 ScrollTrigger 尺寸。3D 循环使用 refs 与对象复用，禁止每帧 React setState。

### 8. 表单、社区和内容的真实功能边界

**申请内测**：优先复用已经存在的报名地址或已验证接口。字段以联系邮箱为必填、角色简介/作品链接为选填；不要求上传完整设定集、模型或私人文件。提交有校验、loading、失败重试、防重复提交，只有真实服务端成功才显示“已收到”。

没有报名接口时，采用邮件申请：按钮文案改为 `邮件申请内测`，打开预填主题的 `mailto:cory@anngel.live`，并提供复制地址。不显示“提交成功”，不把 localStorage 当报名数据库，不自动发送邮件。统一配置 CTA，让以后接入表单无需改所有区块。

**合作**：以已有邮箱联系为最小实现，允许填写或在邮件模板中写作品链接与合作意向。不承诺审核周期、佣金比例或入驻资格。

**意见箱**：分类 `使用问题 / 功能建议 / 其他`，内容、选填联系方式。接好接口才收件；否则让用户复制反馈或打开邮件客户端。不要声称匿名，除非实际收集字段、日志和传输方式支持该表述。限制正文长度并提示勿提交账号密码。

**涂鸦区**：首版实现真实本地画布，支持笔色、笔粗、撤销、清空、导出 PNG；刷新前告知是否已本地保存。提供明确的本地保存提示，导出只含用户画布。公共作品墙只有具备真实存储、授权选择、审核、举报/删除流程后再接入；未接通时不显示虚构投稿和点赞人数。

**Gallery**：仅显示允许公开展示的作品。点击作品查看角色名、原画/模型作者、演示制作方、AI 参与说明及来源链接；不要提供默认模型下载。内测申请、使用服务、官网展示授权不能捆绑成一项。

**Blog / Research**：内容从已有文件或 CMS 读取，未接 CMS 就用本地结构化内容。记录带真实来源；不得捏造论文链接、读者数量、同行评审或用户证言。

**条款**：沿用现有内容并保留草案状态，列出未填字段，不能自动补司法管辖、保留期限、处理者名称或权利代理人。公开发布前需要团队定稿的具体项单列在 `OPEN_ITEMS.md`；本地网站和其余内容照常完成。生产构建应提示/阻止把未定稿占位文案当正式条款发布，但不要阻止本地预览。

### 9. 工程、性能与可访问性

- 页面区块独立成组件；文案、模式状态、素材元数据、联系链接分别配置。不要将网站堆进已有超大 `App.tsx`。
- 默认新增 `src/website/` 或遵循已有同类目录；仅做必要路由接入。保持现有 app、i18n、登录与开播路径可用。
- 首屏可独立显示标题、CTA 和 poster；视频用 `preload="none"` 或 metadata，首屏外图片 lazy-load。不要一次下载整个 VRM 或 GIF 库。
- 静态短循环可转成 WebM/MP4 并配 poster，保留原始来源；设置宽高防止布局跳动。不让多个视频同时自动播放。
- 新增官网首屏压缩 JS 以 200KB 内为优化目标（不含按需视频/3D），首屏图片合计以 500KB 内为目标；给出实测，超出说明具体来源，不伪造达标。
- 正文最小建议 16px；移动端点击区域至少 44×44 CSS px；键盘焦点可见，正常文字对比度达到 4.5:1。真实检查天空背景上的文字与玻璃上的按钮。
- 视频有控制器与字幕；modal 可 Escape 关闭、焦点管理完整；图片有合适 alt，装饰图空 alt。
- 在 390px、768px、1440px 宽度检查，无横向溢出、署名被截断或按钮被固定导航遮挡。
- 使用语义 HTML、唯一 H1、明确 title/description、OG 图；品牌官网正式域名未知时保持配置项，不自行选用资料里的多个域名之一。内部 moodboard 不被索引。
- 不新增默认启用的追踪或第三方广告脚本；第三方视频点击再加载。沿用项目已有隐私设置并记录实际新增的数据流。
